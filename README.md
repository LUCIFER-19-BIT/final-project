## Simple Interest Calculator

The `simple-interest.sh` script computes simple interest using the formula:

```
Simple Interest = (Principal × Rate × Time) / 100
```

### Usage

```bash
bash simple-interest.sh
```

You will be prompted to enter:
1. **Principal Amount** – The initial amount of money.
2. **Rate of Interest (%)** – The annual interest rate.
3. **Time (years)** – The duration of the investment or loan.

The script will then display the calculated simple interest.
